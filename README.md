# GrabExpress

A delivery booking web app inspired by GrabExpress, built for Cebu, PH.

## Features
- Customer booking flow (address → details → review)
- Real-time order tracking
- Driver order management
- Admin dashboard
- Google OAuth login

## Tech Stack
- **Frontend**: React 19, Vite, Firebase
- **Backend**: Node.js, Express
- **Database**: Firebase Firestore
- **Auth**: Firebase Authentication (Google)

## Setup
# 1. Clone the repo
git clone https://github.com/your-username/grabexpress.git
cd grabexpress

# 2. Set up frontend
cd frontend
npm install
# create a .env file here and paste the Firebase keys you shared
npm run dev

# 3. Set up backend (in a separate terminal)
cd backend
npm install
npm start
